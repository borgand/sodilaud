# Sodilaud v0.15.0

A new look: a new icon, tray glyph and fonts, a flatter interface, and Executive as the theme for new installs.

## Highlights

- **New icon.** The app icon shows a board with an amber scrap pinned over its corner, on a coral tile. Small sizes drop detail so the icon stays readable in the Dock, the taskbar and the menu bar.
- **New tray glyph.** The menu-bar icon uses the same board-and-scrap shape.
- **Executive by default.** New installs start in the Executive theme: amber text on a dark ink ground with a teal accent.
- **Bundled fonts.** Inter for the interface and JetBrains Mono for code now ship with the app, so text looks the same on every system, offline.
- **Flatter interface.** The purple glow and the background blur are gone. Focused fields show a solid ring in the theme's accent colour.
- **Website.** The project site uses the new palette, favicon and wordmark.

## Compatibility

- Your saved theme stays as it is, including Default Dark. Choose **Executive** in the theme picker to switch.
- Notes, files, settings and workspaces carry over unchanged.
- Builds are not production-signed; macOS and Windows may display a security warning.
