# Security hardening for the sodilaud fork Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove every outbound network path from the fork, close the privilege-boundary gaps an XSS would weaponize, and put at-rest guardrails in place before a clipboard manager starts storing API tokens.

**Architecture:** Fourteen weeks of upstream code stay intact; the changes are subtractive (kill the updater and its HTTP client), boundary-moving (the Rust side owns the workspace path and the permission surface), and additive (a CI gate that fails when egress capability reappears, plus file-mode and SQLite-purge guardrails). Each task is one branch and one PR so a reviewer can accept one and reject its neighbor.

**Tech Stack:** Tauri v2 (Rust 2021, `rusqlite` bundled, `rmcp`, `rfd`), unbundled ES-module frontend with a hand-written Markdown sanitizer, Node 20 `node --test`, GitHub Actions.

**Spec:** `docs/security/2026-09-25-audit-findings.md` (findings F1-F11, decisions table).

## Global Constraints

- Never commit or push to `main`. Branch from an up-to-date `main`, one PR per task, squash merge (`AGENTS.md`).
- Each task runs in its own git worktree created by `superpowers:using-git-worktrees`.
- Definition of green, every task, before committing: `npm run check` (280 tests baseline) and `cargo test --manifest-path src-tauri/Cargo.toml` (23 tests baseline), plus `cargo fmt --check` and `cargo clippy --all-targets -- -D warnings`.
- After Task 1 the shipped source must contain no HTTP client and no network API: `cargo tree -i reqwest --manifest-path src-tauri/Cargo.toml` must fail with "did not match any packages", and `npm run check:egress` must pass.
- Do not stage `.claude/`. A review agent left untracked notes in `.claude/agent-memory/`; every commit in this plan names explicit paths.
- Do not modify the vendored files under `src/vendor/`; they are regenerated by `scripts/vendor-marked.mjs`.
- Frontend deps are exact-pinned; keep runtime deps exact (`package.json:34-36`).
- Commit messages use `type(scope): description` and end with `Co-Authored-By: Claude Code <noreply@anthropic.com>`.
- No em dashes in user-visible prose.
- Local install used throughout: `npm ci --ignore-scripts --cache "$TMPDIR/npm-cache"`. The npm cache at `~/.npm` contains root-owned files and must be bypassed, not `chown`ed.
- Rust tests cannot run inside the sandbox (`~/.rustup/tmp` is not writable); run `cargo` with the sandbox disabled.

## Review Focus

The spec implies these but no single task's tests cover them, and they are the most likely ways this hardening bites a person using the fork daily:

1. A workspace selected in a previous launch reconnects without a dialog after Task 2 moves path ownership into Rust; a user with a workspace in `~/Documents` would otherwise find their notes "gone" and create a second empty database.
2. Disconnecting a workspace, then relaunching, must not silently reconnect to the last path after Task 2 (`set_last_workspace` becomes derived, not supplied).
3. After Task 3 narrows link opening, a legitimate Markdown link a user clicks must still open in the browser, and must show the real destination rather than the link text.
4. After Task 5 enables `PRAGMA secure_delete`, saving a large collection must not become slow enough that autosave stalls the editor, and a workspace opened read-only (or on a full disk) must produce a clear error rather than a silent data loss.
5. After Task 5 changes the app identifier, existing notes must be findable; the migration must not delete the upstream-identifier directory.

Create `scripts/check-no-egress.mjs`. It scans shipped source for network capability and remote URLs, with a per-file allowlist, and asserts the Cargo and Tauri config invariants:

```js
// SPDX-License-Identifier: GPL-3.0-or-later
// Fails the build when a network capability or a remote URL reappears in shipped source.

import { readFile, readdir } from "node:fs/promises";
import { extname, join, relative } from "node:path";

const ROOT = new URL("..", import.meta.url).pathname;
const SCAN_DIRS = ["src", "src-tauri/src", "scripts"];
const SCAN_EXTS = new Set([".js", ".mjs", ".rs", ".html", ".css", ".toml", ".json"]);
const SKIP_DIRS = new Set(["vendor", "node_modules", "target", "gen"]);
const SELF = "scripts/check-no-egress.mjs";

// Pattern label per file. Each entry is justified in docs/security/.
const ALLOWED = new Map([
  ["src/markdown.js", ["remote url"]],
  ["src/markdown-insert.js", ["remote url"]],
  ["src/index.html", ["remote url"]],
  ["src/welcome-note.js", ["remote url"]]
]);
const RULES = [
  ["network api", /\b(?:fetch|XMLHttpRequest|WebSocket|EventSource|sendBeacon|importScripts)\s*\(/],
  ["rust http client", /\b(?:reqwest|hyper|ureq|isahc|attohttpc|minreq)\b/],
  ["remote url", /https?:\/\/\S/]
];

const findings = [];

async function* walk(dir) {
  for (const entry of await readdir(dir, { withFileTypes: true })) {
    if (entry.isDirectory()) {
      if (!SKIP_DIRS.has(entry.name)) yield* walk(join(dir, entry.name));
    } else if (SCAN_EXTS.has(extname(entry.name))) {
      yield join(dir, entry.name);
    }
  }
}

for (const dir of SCAN_DIRS) {
  for await (const file of walk(join(ROOT, dir))) {
    const rel = relative(ROOT, file).split("\\").join("/");
    if (rel === SELF) continue;
    const allowed = ALLOWED.get(rel) ?? [];
    const lines = (await readFile(file, "utf8")).split("\n");
    for (const [label, pattern] of RULES) {
      if (allowed.includes(label)) continue;
      lines.forEach((line, index) => {
        if (pattern.test(line)) findings.push(`${rel}:${index + 1}: ${label}: ${line.trim().slice(0, 100)}`);
      });
    }
  }
}

const cargo = await readFile(join(ROOT, "src-tauri/Cargo.toml"), "utf8");
for (const crate of ["reqwest", "hyper", "ureq", "isahc"]) {
  if (new RegExp(`^\\s*${crate}\\b`, "m").test(cargo)) findings.push(`src-tauri/Cargo.toml: declares ${crate}`);
}

const config = JSON.parse(await readFile(join(ROOT, "src-tauri/tauri.conf.json"), "utf8"));
const connectSrc = config.app?.security?.csp?.["connect-src"] ?? config.app?.security?.csp ?? "";
if (!String(connectSrc).includes("ipc:") || /https?:\/\/(?!(ipc\.)localhost)/.test(String(connectSrc))) {
  findings.push(`src-tauri/tauri.conf.json: connect-src must stay ipc-only, found ${connectSrc}`);
}

if (findings.length) {
  process.stderr.write(`Egress gate failed. Remove the finding or justify it in docs/security/ and ALLOWED.\n\n${findings.join("\n")}\n`);
  process.exit(1);
}
process.stdout.write("Egress gate passed: no network capability in shipped source.\n");
```

Note: `tauri.conf.json` currently stores `csp` as a single string, so the `connect-src` check handles both shapes; Task 3 converts it to an object.

```rust
// SPDX-License-Identifier: GPL-3.0-or-later
use std::path::PathBuf;
use std::sync::Mutex;

/// The only path the database commands will open. Written exclusively by
/// `select_db_file` (a native dialog) and by startup restoration from native
/// preferences, never by the webview.
#[derive(Default)]
pub(crate) struct Workspace(pub(crate) Mutex<Option<PathBuf>>);

impl Workspace {
    pub(crate) fn set(&self, path: Option<PathBuf>) -> Result<(), String> {
        *self.0.lock().map_err(|_| "Workspace state is poisoned".to_string())? = path;
        Ok(())
    }

    pub(crate) fn path(&self) -> Result<Option<PathBuf>, String> {
        Ok(self.0.lock().map_err(|_| "Workspace state is poisoned".to_string())?.clone())
    }

    /// Returns the connection for the authorized workspace, or `Ok(None)` when no
    /// workspace is connected. Callers must treat `None` as "local storage mode".
    pub(crate) fn open(&self) -> Result<Option<rusqlite::Connection>, String> {
        let Some(path) = self.path()? else {
            return Ok(None);
        };
        let conn = rusqlite::Connection::open(&path).map_err(|e| e.to_string())?;
        crate::ensure_workspace_schema(&conn)?;
        Ok(Some(conn))
    }
}
```
